# RecklessSerum2Bank_1

**250 free presets for Xfer Serum 2.** They are inspired by **2hollis**, **Fakemink**, **Crystal Castles** and **underground electro**.

The presets are generated by code (Python), straight in Serum 2's native `.SerumPreset` format. They use **only Serum 2 factory wavetables and noises**, so there is nothing else to install.

## Installation

1. Download `RecklessSerum2Bank_1.zip` from the [Releases](../../releases) page, or clone the repo.
2. Copy the `RecklessSerum2Bank_1` folder into Serum 2's User folder:
   - **macOS:** `/Library/Audio/Presets/Xfer Records/Serum 2 Presets/Presets/User/`
   - **Windows:** `Documents\Xfer\Serum 2 Presets\Presets\User\`
3. In Serum 2, open the preset menu and go to **User → RecklessSerum2Bank_1**.

```bash
cp -R RecklessSerum2Bank_1 "/Library/Audio/Presets/Xfer Records/Serum 2 Presets/Presets/User/"
```

### The 4 macros (the same on every preset)
| Macro | Effect |
|---|---|
| **1 TONE** | Opens Filter 1 |
| **2 DIRT** | Distortion drive (FX and filter) |
| **3 SPACE** | Reverb and delay amount |
| **4 MOVE** | Wavetable position, or LFO speed on pads/atmos/FX |

### Sound signatures
- **Hyperpop / 2hollis:** 7 to 11-voice supersaws, Hyper/Dimension, multiband OTT, bright reverb, glide.
- **Underground / Fakemink:** distorted 808s and sine waves, tape saturation, light downsampling, mono and dry.
- **8-Bit / Crystal Castles:** C64 squares and pulses, the *Quantize* warp, heavy downsampling, hard clip, vintage reverb.
- **Electro:** 303 acid with resonant ladder filter, reese, FM, Juno PWM, phaser/flanger, ping-pong delay.

## Regenerate / modify

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python tools/generate.py --seed 1312      # regenerates the 250 presets
.venv/bin/python -m unittest discover tests        # validates the bank
```

- `tools/serum2_codec.py` reads and writes `.SerumPreset` files.
- `tools/serum2_model.py` is the high-level API (oscillators, filter, envelopes, LFOs, FX, mod matrix, macros).
- `tools/sounds.py` holds the archetypes per category and style.
- `docs/FORMAT.md` documents the reverse-engineered file format.

Generation needs Serum 2's factory content installed, because the code reads the wavetable headers. The `SERUM2_ROOT` variable overrides the path.
